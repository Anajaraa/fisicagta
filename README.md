# Eletromagnetismo em 2 Horas

Guia de estudo rápido sobre Indução Eletromagnética (Lei de Faraday, Lei de Lenz, fluxo magnético, força de Lorentz, CA x CC e aplicações), com imagens mentais, exemplos concretos calculados e comparações simples — mais um quiz inteligente de 10 perguntas com correção automática e explicações.

## Páginas

- `index.html` — guia de estudo (7 módulos + atalho mental)
- `quiz.html` / `quiz.js` — quiz com correção, explicação dos erros e exemplos
- `style.css` — estilo compartilhado (modo claro/escuro automático)
- `Eletromagnetismo_Guia_de_Estudo.docx` — versão em Word do guia (gerado por `gerar_docx.py`)

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático.
